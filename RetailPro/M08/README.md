# M08 – Checkpoint 2: Modelo de Datos y Medidas DAX

## Objetivo

Construir el modelo analítico en Power BI a partir del pipeline ETL desarrollado en el módulo anterior.

## Contenido

- Archivo Power BI (.pbix)
- Modelo relacional en esquema estrella.
- Tabla calendario (Dim_Fechas).
- Relaciones entre dimensiones y tabla de hechos.
- Cinco medidas DAX:
  - Total Ventas
  - Ventas Online
  - Ventas YTD
  - Ventas LY
  - % Crecimiento Anual
- Página de validación mediante una matriz.

## Herramientas utilizadas

- Microsoft Power BI Desktop
- Power Query
- DAX
