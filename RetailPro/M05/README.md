## Módulo 5 - Consultas con JOINs

Objetivo:
Enriquecer el análisis de datos mediante consultas SQL que integran información de clientes, productos, categorías y ventas utilizando distintos tipos de JOIN.

Contenido:
- INNER JOIN para construir la vista base del proyecto.
- LEFT JOIN para identificar clientes sin compras.
- LEFT JOIN para detectar productos sin ventas.
- UNION ALL para consolidar ventas por canal.
